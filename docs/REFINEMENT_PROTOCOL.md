# 深度修正实验协议

## 问题与可检验假设

固定预训练 3DGS。对同一批有效像素，比较所有方法输出的深度。检验遮挡几何和跨视角纹理同时支持换层时，能否修好部分加权中值的大误差点，并降低只用单项证据时的误修率。大误差按同一物体内统一的阈值判定。椅子和警示牌分别报告，保留所有视角结果。

旧版风险筛查和此前在椅子上的四分位候选预实验用于设计方案。本协议在运行下列保留视角前确定。保留视角的标签仅进入指标计算。单独的对齐视角用于验证坐标和深度约定。

## 从输入到决策

1. 从已有 3DGS 模型和相机参数计算每条射线的有效贡献。默认深度为累计归一化贡献达到一半时的加权中值。
2. 将深度从近到远排列。在候选间隙上检查两侧的归一化质量。只考虑两侧各至少占 10%、间隙至少为 0.012 个归一化模型单位的间隙，取最宽的一个。在两侧各取加权中值作为前后候选。没有合格间隙时保留默认中值。
3. 只考虑投影累计不透明度至少 0.35 的像素。选与目标相机朝向场景中心的方向最接近的四个辅助视角，排除本组的目标视角和对齐视角。几何判断使用辅助视角的 3DGS 加权中值。辅助像素需要累计不透明度至少 0.50，且 10–90% 深度跨度不超过 0.045 个归一化模型单位。
4. 设投影点与辅助深度的差为 r。正差表示点在辅助表面后面。|r|≤0.012 表示支持，r>0.012 表示可能被遮挡而跳过，r<−0.012 表示与可见的自由空间冲突。图像越界或辅助深度不可靠时不作几何判断。
5. 光度检查用数据集 RGB 图转换的亮度。在候选深度处把目标图 3×3 小块投到辅助图，使用双线性采样。仅当两个小块的亮度标准差均至少为 0.02 时计算零均值归一化互相关。将代价定义为 (1−相关系数)/2。候选代价在同一视角至多 0.25 且比默认中值低至少 0.06 时，该视角提供光度支持。默认中值在该视角的光度代价也必须有效。
6. 单项几何版本要求至少两个几何支持、零自由空间冲突，且支持数超过默认中值。单项光度版本要求至少两个光度支持。联合版本要求至少两个**同一视角内两项都通过**的证据，且无自由空间冲突。首先比较证据总数。光度和联合版本对同票候选比较支持视角上的平均代价改善量。继续并列时优先较小的改动，仍平局时取较近候选。三种版本都只允许替换与默认中值相差至少 0.006 个归一化模型单位的候选。证据不足时保留默认中值。

几何容差和候选间隙以归一化模型尺度设置，光度容差以 [0,1] 的亮度和匹配代价设置。它们是待验证的固定设计选择，阈值来源记为方案设计，不能解释为最优值。亮度来自原始配套 RGB，真值深度没有参与候选或打分。

## 试验分组和评价

| 组别 | 目标视角编号 | 用途 |
| --- | --- | --- |
| 椅子开发 | 14、36、58、80、102、124、146、168 | 此前预实验，作为开发环境 |
| 椅子保留 | 12、34、55、75、99、120、143、177 | 同物体新视角，在两个早期预实验中未用作目标或辅助视角 |
| 警示牌 | 12、34、55、75、99、120、143、177 | 不同物体，使用同一方案 |
| 坐标核对 | 29、94、157 | 核对 PLY 坐标及参考深度约定 |

默认图像尺寸为 128×128。对照包括加权平均、加权中值、仅使用几何、仅使用光度、联合证据。使用共同有效像素，所有方法均输出深度。报告每视角 MAE、大误差率、改动数、修好数、改坏数，以及改动范围内的净收益。修好表示中值原先超过阈值而新深度回到阈值内，改坏表示相反。阈值沿用 0.05 个数据集场景单位，并补报 0.025 与 0.10 的敏感性检查。视角宏平均与像素计数分别统计。

候选上限用参考深度在中值、前候选、后候选中事后选最接近者，仅用于诊断。用这个上限区分「正确候选没有出现」和「候选出现但证据没选中」。同一模型的多个视角并非独立物体，报告采用描述性比较。

几何重投影和遮挡判断参考多视角深度融合。联合方法的假设检验范围是固定已有模型的深度重新选择。[Merrell 等，ICCV 2007](https://mordohai.github.io/public/Merrell_DepthMapFusion07.pdf) · [GVGS](https://arxiv.org/abs/2601.20331)
