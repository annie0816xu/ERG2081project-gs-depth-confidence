# 深度修正的后续对照

这一轮比较两个增加候选的方法。第一种将射线分层的最低合成权重从 10% 降到 5%，允许弱贡献的表面进入候选。第二种把邻近视角中可靠的深度投回目标视角，再由其他视角核对。两种方法使用相同的 3DGS 模型、相机与 128×128 评估图像。三个对照组各有 8 个目标视角，沿用已有划分。

## 分层权重从 10% 降到 5%

两版都按深度间隙做分层，并使用原几何规则核对。每条射线最多提出两个替代深度。下表用 0.05 个场景单位作为大误差阈值。可修复数用参考深度事后计算，表示至少一个候选能达到阈值的原始错误像素数。修对和误修都相对于加权中值。

| 组别 | 可修复数 10% → 5% | 原几何 MAE | 5% 几何 MAE | 原几何 修对 / 误修 | 5% 几何 修对 / 误修 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 椅子开发组 | 506 → 621 | 0.043625 | 0.043506 | 51 / 12 | 56 / 13 |
| 椅子原保留组 | 631 → 770 | 0.044883 | 0.044811 | 58 / 14 | 64 / 16 |
| 警示牌原保留组 | 131 → 162 | 0.048403 | 0.048266 | 35 / 4 | 38 / 4 |

两个原保留组的净修复数从 75 增至 82。0.025 和 0.10 两个误差阈值下，三组也都增加了净修复数。结果支持弱层门槛对这两个物体有小幅帮助。两个对象及其原保留组都曾在项目中分析过，这轮属于复测。跨物体泛化还需要新对象检验。

## 弱候选三票规则

先用 10% 门槛和原来的两票几何规则生成深度。只在原版没有改动的位置，考虑统一 5% 门槛额外提供的深度。新增候选必须在四个邻近视角中获得至少三票几何支持、比原中值获得更多支持，且没有自由空间冲突。三个条件不满足时保留第一步的结果。

三个版本在同一个 CPU 运行中共享模型、相机和有效像素。椅子和警示牌沿用已分析过的视角，电钻为新加入的物体。下表每个格子列出平均绝对深度误差（MAE）和阈值 0.05 下的修对、误修数。每个物体有 8 个评估视角。

| 评估组 | 原版 10% MAE · 修对 / 误修 | 统一 5% MAE · 修对 / 误修 | 弱候选三票 MAE · 修对 / 误修 |
| --- | ---: | ---: | ---: |
| 椅子原保留组 | 0.044883 · 58 / 14 | 0.044811 · 64 / 16 | 0.044856 · 59 / 14 |
| 警示牌原保留组 | 0.048403 · 35 / 4 | 0.048266 · 38 / 4 | 0.048292 · 37 / 4 |
| 电钻 | 0.020684 · 15 / 6 | 0.020656 · 17 / 6 | 0.020684 · 15 / 6 |

三组总计，原版修对 108 个、误修 24 个，统一 5% 修对 119 个、误修 26 个，三票版修对 111 个、误修 24 个。三票版在椅子和警示牌上合计多修对 3 个。电钻没有新增候选通过三票规则，两个版本的读数一致。统一 5% 的 MAE 在三个物体上均最低。椅子开发组在三个阈值下的独立记录也随包保留。

逐视角 CSV 中，`geometry`、`geometry_mass05`、`geometry_weak_guard` 分别对应上述三版。`eligible_targets`、`recoverable` 和 `oracle_bad` 记录 10% 基线的候选诊断，供同次运行对照。[三票规则逐视角记录](../evidence/followup/weak_layer_guard/) · [电钻数据](https://dx.gl/datasets/A0dcsk7HHgAg)

## 邻视角重投影的对照

每个邻近视角将可靠的中值深度反投影到三维，再投回目标相机。同一目标像素内来自同一视角的点保留最近深度。原几何规则已经修改的像素保持该结果。对于其他像素，候选至少要获两张其他视角的几何支持，在相同的验证视角中比原中值获得更多支持，且可靠视角中没有自由空间冲突。提出候选的视角不计赞成票。

- 仅用几何检查邻视角候选时，椅子和警示牌原保留组的理论可修复数分别从 631 增至 1,225 和从 131 增至 490。实际净修复合计从 75 降至 23。
- 如果要求至少一个验证视角的 3×3 图块匹配也有改善，净修复合计为 74。椅子少量受益，警示牌多了两次误修。
- 再允许至少三个视角一致的小幅深度更新，两组的 MAE 均高于原几何规则。小幅调整也会将一部分原本合格的像素推过误差阈值。

候选覆盖可以继续增加，实际收益取决于能否用其他视角可靠地排除错误候选。当前这组数据更支持优先试弱层门槛。

## 逐射线高斯深度

中心深度版把同一个高斯的中心 Z 分配给它覆盖的所有像素。对于倾斜或拉长的高斯，相邻像素实际对应不同的射线，射线上高斯响应最高的位置也可能不同。这会在生成分层候选和跨视角投票之前影响深度。

在相机坐标中，把像素射线写成 $t\mathbf r$，其中 $r_z=1$，所以 $t$ 就是相机 Z。对中心 $\boldsymbol\mu$、协方差 $\Sigma$ 的高斯，最小化 $(t\mathbf r-\boldsymbol\mu)^T\Sigma^{-1}(t\mathbf r-\boldsymbol\mu)$，得到射线上响应最大的深度。

$$
t^*=\frac{\mathbf r^T\Sigma^{-1}\boldsymbol\mu}{\mathbf r^T\Sigma^{-1}\mathbf r}.
$$

每个像素按各高斯的 $t^*$ 重新排序，再合成深度。实现沿用原先的二维投影和每个高斯的像素不透明度，比较逐射线深度计算和排序的共同影响。射线最大响应位置若越过相机近面或数值无效，则用中心深度。[Gaussian Opacity Fields，式 6](https://www.cvlibs.net/publications/Yu2024SIGGRAPHASIA.pdf) · [StopThePop，第 3.2 节](https://r4dl.github.io/StopThePop/static/paper/StopThePop.pdf)

两版使用同一组模型文件、相机、每物体 8 个目标视角和每视角 4 个邻近视角，分辨率 128×128。下表比较旧版最好的 5% 几何结果、只用逐射线加权中值，以及结合逐射线深度和原 5% 几何规则的结果。大误差数使用 0.05 个场景单位的阈值。

| 物体 | 中心深度 + 5% MAE | 逐射线中值 MAE | 逐射线 + 5% MAE | 相对旧版变化 | 大误差数（旧 → 新） |
| --- | ---: | ---: | ---: | ---: | ---: |
| 椅子 | 0.044811 | 0.043669 | **0.042568** | −5.00% | 5,892 → 5,358 |
| 警示牌 | 0.048266 | 0.047901 | **0.046906** | −2.82% | 2,650 → 2,206 |
| 电钻 | 0.020656 | 0.018531 | **0.018437** | −10.74% | 2,141 → 2,083 |

逐射线 + 5% 在 24 个配对视角中的 21 个降低了 MAE。81,170 个共同有效像素中，大误差数从 10,683 降至 9,647，相对减少 9.7%。逐射线中值在三个物体上的 MAE 已低于旧版 5% 几何，说明收益在投票前就已出现。几何规则对逐射线中值仍有增益。以上为三个已有合成对象上的深度图验证，点云或表面精度仍需用独立指标验证。[逐射线结果和数据指纹](../evidence/followup/ray_depth/) · [中心深度配对对照](../evidence/followup/weak_layer_guard/)

## 复现

模型按 README 下载到 data/。以下命令以椅子原保留组为例。加 --split development 可重复椅子开发组，将 --object chair 换成 --object sign 可重复警示牌。报告同时保留 0.025、0.05 和 0.10 三个误差阈值的逐视角记录。

~~~powershell
python -m gsdepth.benchmarks.run_refinement --object chair --layer-mass 0.05
python -m gsdepth.benchmarks.run_refinement --object chair --reproject
python -m gsdepth.benchmarks.run_refinement --object chair --weak-layer-check
python -m gsdepth.tools.fetch_chair --object drill
python -m gsdepth.benchmarks.run_refinement --object drill --weak-layer-check
python -m gsdepth.benchmarks.run_refinement --object chair --weak-layer-check --ray-depth
~~~
