# 风险分敏感性、实现核对与三维点云验证

## 风险分从哪里来

风险筛查阶段使用手工定义的评分函数。沿射线对高斯按深度排序，每个高斯的权重是该处不透明度乘以前方的剩余透射率。把权重除以总权重后，累计权重第一次达到 10% 和 90% 的位置分别记为 $z_{10}$ 和 $z_{90}$。跨度 $z_{90}-z_{10}$ 大的像素优先标为可疑。10% 和 90% 是为减少两端低权重尾部影响而选的启发式分位点。

这两个分位点决定风险跨度，也用于辅助视角深度的可靠性筛查。分层候选使用另一项门槛，要求深度间隙两侧各有至少 5% 的累计合成权重。0.05 个场景单位则是评估误差时的距离阈值。

以相同的中心深度加权平均来打分，对照累计贡献区间 5%–95%、10%–90% 和 15%–85%。所有方法在同一视角各保留 90% 的有效像素，分数相同时使用固定随机种子排序。每个表格读数是 8 个视角的平均 MAE。

| 物体 | 5%–95% | 10%–90% | 15%–85% | 深度梯度对照 |
| --- | ---: | ---: | ---: | ---: |
| 椅子 | 0.035851 | 0.036734 | 0.037663 | 0.031518 |
| 警示牌 | 0.044440 | 0.044722 | 0.044999 | 0.036647 |
| 电钻 | 0.017984 | 0.018169 | 0.018276 | 0.016728 |

这三组上，5%–95% 的 MAE 在三个跨度区间里最低。深度梯度的 MAE 更低，10%–90% 则保留了更多原本正确的边缘像素。例如电钻分别保留 89.64% 和 93.92%。这一轮只检验早期风险排序的敏感性。逐射线几何修正沿用原先登记的分位数。[分位数与四种风险分逐视角数据](../evidence/risk_sensitivity/)

## 三维点云怎么验证

1. 重新跑中心深度和逐射线深度版，两版都用 5% 分层和相同的几何核对规则。两个运行的逐视角 CSV 必须与原始存档逐字节一致。
2. 使用此前检查过的相机 Z 约定。预测深度除以记录的训练坐标尺度，再用数据集原始相机反投影到数据集世界坐标。对照版、新版和参考深度都使用同一批像素。每个物体合并 8 个视角，每个有效像素生成一个点。
3. **贴近度**把预测点匹配到数据集提供的整物体参考点云中的最近点，统计三维欧氏距离。**可见覆盖**反过来测参考可见点到预测点云的距离。只统计能投影到配对掩码内，并与原分辨率参考深度相差不超过 0.01 个场景单位的参考点。
4. 报告平均距离、P95、距离超阈值点数和不同距离阈值下的 precision、recall、F1。另将从相同 128×128 像素反投影的参考深度当作正对照，检查参考点采样带来的误差。所有匹配直接使用源相机坐标。两版共用同一坐标变换。

参考点云来自原物体的参考深度采样。最近点距离在三维空间计算，允许匹配到另一条射线上的参考点。配对深度 MAE 仍用于检验目标像素的深度精度。精确网格的点到面距离需要额外的网格和坐标核验。[DX.GL 数据说明](https://huggingface.co/datasets/dxgl/multiview-datasets) · [双向点云距离度量参考](https://tanksandtemples.org/tutorial/)

| --- | ---: | ---: | ---: | ---: |
| 椅子 | 0.019647 → 0.017651 | 0.082142 → 0.079772 | 2,372 → 2,251 | 93.79% → 93.97% |
| 警示牌 | 0.010470 → 0.009811 | 0.020320 → 0.019171 | 0 → 0 | 99.56% → 99.67% |

每个物体的公开参考点云包含 100,156 个点，其中椅子、警示牌、电钻分别有 85,205、92,911、90,885 个点满足可见覆盖条件。两版分别共同覆盖 30,366、28,931 和 21,873 个前景像素，等于这三组的全部有效参考前景像素。不同视角可以重复采到同一表面。

### 参考采样敏感性

用相同八视角的参考深度以 256×256 重采样，反投影得到更密的可见参考，同时保留 128×128 预测点云。这个对照改变了参考点密度和参考范围。

| 物体 | 密参考下平均最近点距离 | 密参考下距离超过 0.05 的点数 |
| --- | ---: | ---: |
| 椅子 | 0.018853 → 0.017651 | 2,467 → 2,358 |
| 警示牌 | 0.009677 → 0.009885 | 0 → 0 |
| 电钻 | 0.010724 → 0.010132 | 522 → 645 |

椅子在两套参考下都更贴近，且离群点更少。电钻的平均距离都下降，离群点都增加。警示牌的平均距离方向随参考采样和范围而变。警示牌的参考深度正对照在公开点云下有 101 个超 0.05 的点，换成密参考后为 0，也说明参考采样会影响该物体的三维读数。[每物体和每视角三维指标](../evidence/surface_validation/) · [图 6](../figures/fig6_surface.pdf)

## 实现逐步核对

| 环节 | 检查 |
| --- | --- |
| 数据 | 三个模型和参考文件均匹配存档 SHA-256。各对象的辅助视角、配置和视角编号均复核。 |
| 坐标 | OpenGL 相机约定转换为渲染器约定。用 3 个专用校准视角检查轮廓，选中坐标约定下的轮廓 IoU 为 0.868–0.920。参考点云投影验证相机 Z 约定。 |
| 渲染 | 单测覆盖按透射率累加、按贡献分位数取值、分层中值和逐射线极值。逐射线选择使用相同的屏幕覆盖与单片不透明度。 |
| 候选与投票 | 单测和重跑覆盖支持、被遮挡、自由空间否决、缺证据和保留原修改等情况。主实验的目标视角不在该实验的辅助视角或校准组里。 |
| 参考深度 | 模型坐标与数据场景单位分开。目标视角的参考深度在选值后才读取。校准采用另外三个预先固定的视角。 |
| 输出与复现 | 原有六组合成风险记录重跑匹配；三组预训练模型上的两个版本共 6 份深度指标 CSV 与存档逐字节一致。三维正对照反投影和投影后还原相同像素中心与相机 Z。 |

现有 3 个预训练模型来自同一合成数据源、同一训练体系。24 个目标视角可用于对象内配对描述，81,170 个像素作为评估点，物体才是泛化讨论的样本层级。保留视角的划分适用于修正算法，本项目没有重做公开 3DGS 的训练划分。扩大到独立采集场景和更不同的形状后，才能检验是否有稳定的跨场景收益。

## 复现

安装项目依赖并按 README 下载模型后，在项目根目录运行。对象参数可以选择 chair、sign 或 drill。

~~~powershell
python -m unittest discover -s tests
python -m gsdepth.benchmarks.risk_sensitivity --object chair
python -m gsdepth.benchmarks.surface_validation --object chair
~~~

三维验证在 results/surface_validation/ 中生成新旧点云、参考深度对照点云和 CSV。分位数检查在 results/risk_sensitivity/ 下保存比较结果。
